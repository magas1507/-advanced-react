# Performance Patterns in React ⚛️

This repository contains my notes, exercises, and the practical project developed during the Platzi course **[Rendering Patterns in React](https://github.com/platzi/rendering-patterns-in-react-base)**.

The main objective is to delve deeper into component architecture and optimization of modern applications.

## 🚀 Technologies Used
* **React** (Hooks, Context API)
* **TypeScript** for robust, typed development.

* **Node.js** and dependency management.

## 🧠 Design Patterns Implemented
Throughout the course, I applied the following patterns to improve code readability and maintainability:
* **Render Props:** To share logic between components.

* **High Order Components (HOC):** Reusing component logic.

* **Compound Components:** Creating declarative and flexible components.
* **Control Props:** Allowing the user to control the component's internal state.
